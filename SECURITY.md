# Security policy

sew-str0m and sew-str0m-is, Alakazam Labs' fork of str0m, follow the Sew crates policy:
https://github.com/Alakazam-211/sew-crates/blob/main/SECURITY.md

Report a problem privately, as that policy describes. Do not open a public issue for it.

Other bugs in the fork's patches go to https://github.com/Alakazam-211/sew-crates/issues with the
`crate:sew-str0m` label (`crate:sew-str0m-is` for that crate); bugs in str0m itself go upstream
to https://github.com/algesten/str0m/issues.
